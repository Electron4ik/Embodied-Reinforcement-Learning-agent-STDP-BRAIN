# Embodied-Reinforcement-Learning-agent-STDP-BRAIN
Принципиально новая модель симуляции нейронов, использующий спайковые нейросети.
"Мозг" разделен на 3 части, которые по отдельности решают что сделать, и насколько они оценивают то, что сделали.
Обучение происходит при помощи дофамина и боли.
Работает по TCP, чтобы обеспечить удобную интеграцию с другими языками и проектами
